# Laboratorio 09: JavaScript ES6+

## Objetivo

Refactorizar un programa de JavaScript ES5 a ES6+ utilizando módulos.

## Contenido

- `datos.js`: almacena el curso y los estudiantes.
- `calculos.js`: calcula promedios y estados.
- `app.js`: muestra los reportes en la página.
- `index.html`: interfaz del programa.

## Características utilizadas

- `const` y arrow functions.
- Parámetros por defecto.
- Desestructuración.
- Operadores spread y rest.
- Template literals.
- Módulos con `import` y `export`.
